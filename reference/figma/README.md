## 시안 vs 확정 전제 차이 — 2026-09-02 사용자 결정 (09 §0 2026-09-02(5))

1. 로그인 폼에 2차 인증 칸 없음 → 2단계 분리인지 (기획: 단일 폼)
2. 오류 칩에 남은 시도 횟수 노출 ("2회 남음") (기획: 미표시 [확인필요])
3. 2FA 코드 실패도 "2회남음" 카운트 (기획: 2차 인증 실패는 잠금 카운트 대상 아님)
4. 복구 코드 = 단일 코드 1개 + 복사/다운로드 (기획: 8자리 백업코드 6개)
5. 2FA 설정 키 수동 입력 노출 · 문의하기 링크 · 로그인으로 돌아가기 (기획에 없음)
6. ONB-01이 3단계([다음] 진행)로 분리 (기획: 한 화면) → 2026-09-02 시안 프레임 단위로 ONB-01/02/03 3화면 분리
7. DASH-02/03이 콘솔 밖 독립 페이지 레이아웃 (기획: 콘솔 내 화면)
8. 계정 잠금 배너 · 초대 링크 만료 배너 시안 없음
9. 서비스명 'DSRV Portal/Console' (확정: DSRV Desk)

결정: 1 2단계 채택 · 2 노출 · 3 합산 카운트 · 4 단일 복구 코드 · 5 3단계 분리 · 6 독립 페이지 · 7 시안 없는 요소는 기획 유지(디자인 요청) · 8 DSRV Desk. 9(서비스명)는 8과 동일.

## 디자인 요청 목록 (시안에 없어 기획으로 추가한 요소)
- AUTH-01: 로그인 2단계(코드 입력) 프레임 · '복구 코드로 인증' 전환 + 입력 필드 · 계정 잠금 배너
- ONB-00: 1조직 1계정 고지 박스
- ONB-01: 초대 링크 만료/사용됨 배너 · 규칙 ○/✓ 실시간 표시
- ONB-02: 등록 완료 상태(ONB-03 이전으로 복귀 시) 표시 · 재진행 수단
- ONB-03: [확인] 확인 다이얼로그
- DASH-02: [취소] 버튼 · 주기 변경 권고 1줄 · 버튼 라벨 '다음' 조정
- DASH-03: 발송 결과 배너 · 마스킹 이메일 명시 · '백업코드' → '복구 코드' 용어
