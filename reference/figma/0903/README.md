## 4. 결정이 필요한 항목(요약)
1. **복구 코드 로그인 후 2FA 초기화 여부**(#15) — 시안은 초기화·재로그인, 스토리보드는 세션 생성 + DASH-03 권고. 인증 흐름 전체에 영향.
2. **복구 코드 인증 UI** — 같은 화면 토글(스토리보드) vs 별도 화면(시안, #14).
3. **9-02 삭제 결정의 유지 여부** — 규칙 안내 블록(#4·#19), 보조 링크 문의하기·돌아가기(#8·#10·#17), [다운로드](#9), 잔고 고지 문구(#30), 계정 카드 부제(#32). 시안이 전부 되살렸으므로 한 번에 결정.
4. **ONB-01 만료 처리 위치** — 동일 화면 칩(시안) vs ONB-04 별도 화면(스토리보드, #3).
5. **이메일 마스킹** — ONB-01 초대 박스·DASH-03 발송 결과(#7·#22).
6. **콘솔 셸** — 사이드바 레이아웃 채택 여부 · 배지 내용(ORG명 vs 이메일) · 로그아웃 진입(#24·#25).
7. **EXC-03/04 종료 동선** — [확인] 버튼 vs '이전으로'(#54·#65).
8. **DASH-01 오입금 안내 배너** 채택 여부(#31) — 채택 시 문구 법무 확인.
9. **EXC-04 완료 시 '받은 자산' 정의** — 스토리보드 내부 불일치(#63) 먼저 확정.
