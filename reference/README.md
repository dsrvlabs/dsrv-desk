# reference/ — 벤치마크·사업맥락 (근거 아님)

경쟁·벤치마크·장기 사업맥락 자료. 규제 근거로 직접 인용 금지. 여기 담긴 규제 사실은 원문 검증 후에만 [knowledge/09](../knowledge/09_원천자료_목록.md) §1-C로 승격. 분류 근거는 knowledge/09 §3.

| 파일 | 성격 |
|---|---|
| 웨이브릿지_벤치마크_대화 | 중개 스펙트럼 정의 + 매매/중개 규제 경계 분석 (R1~R3 근거, [원문대조필요]) |
| portlogics_RTVS_사업협력_v1.0_20260623 | Portlogics→DSRV 제안. 발행=은행/정산=DSRV/검증=RTVS/결제=PG |
| portlogics_IBK_공동제안_v1.0_20260702 | Portlogics×DSRV→IBK. 중소기업 무역대금 스테이블코인 DvP 정산 실증 |
| portlogics_teaser_20260608 | Portlogics 회사소개(디지털 포워더, ~2조원 무역대금 통과) |

- `.pdf` = 원본, `.txt` = 추출본. **Portlogics PDF 추출본은 숫자·띄어쓰기 유실** — 정확한 수치는 반드시 원본 PDF 확인.
- 용도: `knowledge/00` 고려사항 "은행 연동·무역사 연동" 입력값. 현재 라이선스 취득의 직접 근거 아님.
