# 웨이브릿지(돌핀) 벤치마크 — AI 대화 정리

- 성격: 참고자료(reference). 벤치마크 분석 + 규제 경계 논의.
- 출처: 사용자–AI 대화(2026.6~7경). 규제 사실은 [원문대조필요] — 검증 후 `knowledge/09` §1-C(R1~R3)로 승격.
- 요지만 정리(원문 대화는 세션 로그 참조).

## 1. 웨이브릿지 = B2B 기관 대상 프라임 브로커리지
- 리테일 아님. 법인·기관 전용. 커스터디·거래·정산 인프라를 한곳에서 제공.
- 타깃: BTC 현물 ETF 운용사 / 원화 스테이블코인 사업자 / DAT(디지털자산 비축) 법인.
- 기능 4축: Brokerage(블록딜 중개) · Custody · Digital Asset Management(세무·회계·리포팅) · Wave Pricing Engine(공정가·Greeks).
- 신뢰 레이어: VASP 신고수리(등록 2024-04) + ISMS(ISMS-KISA-2025-053). 규제 획득 자체가 제품의 일부.

## 2. "중개"의 스펙트럼
- **게시판형**(최약): 의향만 게시, 당사자끼리 만남. 플랫폼은 가격·검증·정산 책임 없음.
- **에이전시 브로커형**(중간): 브로커가 상대를 찾아줌. 가격은 당사자 협상. 수수료 수취.
- **딜러/프린서플형**(최강): 브로커가 직접 호가 제시·상대가 됨. "내가 상대다".
- 웨이브릿지 = **에이전시 + 딜러 혼합** (게시판형 절대 아님). 비공개 매칭·상대검증·정산보증·가격산출까지 능동 개입.

## 3. 규제상 문제 — 매매/중개 경계 (핵심)
- **2026 초 업비트·코빗 갱신 시 FIU가 5유형 중 이전·보관관리·중개알선대행 3개만 갱신, 매도·매수/교환 2개 제외.** → 거래소는 '중개 플랫폼'만, 자기자본 '거래 주체'는 불가. (MiCA식 업권 분리)
- 중개·알선·대행 = 남의 거래 연결·매칭(에이전시) → 현 VASP 중개 유형으로 커버.
- 매도·매수/교환 = 자기자본으로 거래 상대방(딜러) → 별도 유형, 당국이 지금 신규 미발급.
- 2026-08-20 진입규제·재신고 시행(대주주 적격성·부채비율·AML 4인·결격 확대). 신고 = 유지 조건부 자격(갱신=재심사).
- 크로스보더 시 외국환거래법상 기재부 등록 별도 축.
- 당국이 열어둔 방향: 기관 수탁 전문 / OTC·브로커형 중개 / 전통 금융 결합 자회사.
- 다윈KS 사례: "환전만 한다" 주장에도 FIU는 통화↔가상자산 교환을 매매·교환으로 넓게 판단. → 교환 해석이 넓음.

## 4. 웨이브릿지 vs DSRV
- 웨이브릿지: 돌핀 기준 **교환+중개** 다 받음 → 딜러적 프라임 브로커리지가 교환 위에서 돎.
- DSRV: **이전+보관·관리만** 보유(매매·교환·중개 없음). 커스터디+이전 중심.
- 매매를 피하는 DSRV 모델 원칙: **전환의 당사자·가격 결정 주체가 되지 않는다.**
  - 모델 A: 순수 커스터디+정산(DvP) 레일 — 현 라이선스와 정합(단 코인↔코인 스왑은 교환 재분류 위험 → 양다리를 각각 독립 이전으로).
  - 모델 B: 에이전시 중개(중개·알선 유형 추가) — 상대만 붙이고 체결·전환은 외부.
  - 모델 C: 라우팅 오케스트레이터/기술 제공(수수료 비연동 SaaS) — VASP 해당성 최소화.
- 단서: 세부 수리유형은 기사 기반 요약([원문대조필요]), "DvP 정산을 매매 아닌 이전으로 볼 수 있는가"는 [로펌게이트].
