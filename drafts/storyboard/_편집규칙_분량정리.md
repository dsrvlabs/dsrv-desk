# 스토리보드 분량 정리 규칙 — 2026-09-22

사용자 지시: "글이 너무 많다. 중복되는 내용 다 지우고 진짜 필요한 내용만."
새 정책이 아니라 `_TEMPLATE_component.md`의 기존 원칙을 강제 적용하는 작업이다.

착수 시점 분량(26화면 합계 120,273자): 항목설명 66,332 · 개정노트 27,363 · 인터랙션 25,266 · 목업주석 1,312.

## 남기는 것 — 지우지 않는다

1. **정책값** `{정책값 ...}` 토큰과 수치. 검색용 토큰 형태까지 유지.
2. **`[확인필요]` · `[결정필요]` · `[로펌게이트]` · `[디자인 요청]`** 전부.
3. **`.basis` 근거 줄.** 규제 산출물의 근거는 근거다.
4. **폐기된 전제** — "종전 X는 폐기". 지우면 개발이 구 스펙으로 구현한다.
5. **문구 원문** — 오류 메시지·다이얼로그 본문·라벨.
6. **템플릿 필수 줄** — 입력창 1(입력 가능)·5(연동) / 버튼 1(노출)·3(확인 사항)·4(액션).

## 옮기는 것 — 삭제 금지

**M1. 개정 노트에만 있는 스펙**은 해당 항목 설명 또는 `notation.html`로 옮긴 뒤 노트에서 지운다.
예: `auth-01` 비밀번호 규칙 ①~⑦, `dash-01` 목록 전량 표시 규칙.
옮길 곳이 없으면 노트에 남긴다 — 스펙 유실이 분량보다 나쁘다.

**M2. 조건이 3개 이상 갈리는 산문**은 표로 바꾼다. 상태·활성 조건 매트릭스가 대표 사례다.
