2차 인증 재설정
인증 앱을 새 기기로 옮기거나 백업코드를 다시 받으려면 재설정하세요.
본인 이메일로 재설정 링크가 발송되며, 링크에서 비밀번호 재설정과 2차 인증 재등록을 진행합니다.
※ 재등록이 끝나면 새 백업코드가 발급되고 이전 코드는 모두 폐기됩니다

2차 인증 재설정필수
· 버튼 클릭 → 본인 이메일로 재설정 링크 발송(초대 재발송 ONB-00 재사용 — 신규 화면 없음)
· 링크에서 비밀번호 재설정 + 2차 인증 재등록(ONB-01 절차 재수행)
· 완료 시 새 백업코드 발급·이전 코드 전량 폐기 · 기존 세션 전체 로그아웃
· 2FA 재인증 입력 없음 — 기기 분실 상태에서 진입하는 화면이므로 코드 입력을 요구하지 않고, 본인 확인은 본인 이메일 링크 수신으로 갈음
근거: 인증수단 재등록 · 정보보호 관리체계(ISMS) 인증기준 2.5(인증)
화면 이동 · 인터랙션
[재설정 이메일 발송] 버튼클릭 — 본인 이메일로 재설정 링크 발송(ONB-00 재사용) · 발송 이력 감사기록화면 이동 없음 — 발송 완료 안내 표시 · 이후 흐름: 이메일 링크 → ONB-01 재수행(비밀번호 재설정 + 2FA 재등록) → 완료 시 새 백업코드 발급·기존 세션 전체 로그아웃 → AUTH-01 재로그인
상세내용
1진입 경로 · 재설정 흐름
· 대시보드(DASH-01) → 계정·보안 → '2차 인증 재설정'에서 진입 · 화면은 이 단락 하나(안내문 + 발송 버튼) · 비밀번호 수정은 별도 화면(DASH-02)
· 발송 → 이메일 링크(ONB-00 방식) → 활성화·재등록(ONB-01) → 새 백업코드 발급
· 기기 분실로 로그인 자체가 안 되면: 백업코드 로그인(AUTH-01) 후 이 화면에서 재설정
· 백업코드까지 분실·소진 시 DSRV 관리자 본인확인 후 초대 재발송(운영 처리)
· 발송·재등록·폐기 이력은 감사로그 기록
비고
· 대시보드(DASH-01) 계정·보안의 '2차 인증 재설정' 진입 화면 — 안내문 + 발송 버튼만 있는 최소 화면.
· [백엔드 통제] 발송·재등록·폐기 이력은 화면 표시 없이 감사기록으로 보존 — 근거: 정보보호 관리체계(ISMS) 인증기준 2.9.4.
· 이전: 대시보드(DASH-01) · 관련: 비밀번호 수정(DASH-02) · 재등록 절차: 계정 활성화(ONB-01)
