1
▼ 자발 모드 (DASH-01에서 진입)
인증 앱을 새 기기로 옮기거나 복구 코드를 다시 받으려면 재설정하세요. 본인 이메일 {담당자 이메일}로 재설정 링크가 발송되며, 링크에서 비밀번호 재설정과 2차 인증 재등록을 진행합니다.

※ 재등록이 끝나면 새 복구 코드가 발급되고 이전 코드는 모두 폐기됩니다. 재등록 완료 전까지 현재 인증 앱·복구 코드는 그대로 사용할 수 있습니다.
▼ 강제 모드 (복구 코드로 로그인해 AUTH-03에서 진입)
인증 앱을 다시 등록해야 서비스를 이용할 수 있습니다. 본인 이메일 {담당자 이메일}로 재설정 링크가 발송되며, 링크에서 인증 앱 재등록과 새 복구 코드 발급을 진행합니다.

※ 재등록이 끝나면 새 복구 코드가 발급되고 이전 코드는 폐기됩니다. 재등록 완료 전까지 현재 복구 코드로 다시 로그인할 수 있습니다.

진입 · 전역 이동
· 전역 이동 프레임(브랜드 패널 · 푸터 · 뒤로가기)의 동작은 계정 활성화 1/3 비밀번호 설정(ONB-01)의 표와 같다. 다른 점 없음(브랜드 패널에 'DSRV 서비스 소개 보기 →' 링크가 없는 것도 ONB-01과 같다). 로그인 상태 화면이지만 콘솔 상단 메뉴(GNB)와 기관 배지가 없어 다른 콘솔 화면으로 바로 갈 수 없고 로그아웃 메뉴도 없다.
· 진입 2종 — 진입 경로에 따라 재설정 범위·나가기·완료 후 이동이 갈린다(2026-09-17 신설).
  ① 자발 모드: 대시보드(DASH-01) 계정·보안 영역의 '2차 인증 재설정' 카드 클릭. 범위 = 비밀번호 + 2차 인증. 메일 토큰 모드 full → ONB-01부터 재수행.
  ② 강제 모드: 복구 코드로 인증(AUTH-03) 성공 직후 자동 이동. 계정이 재설정 대기 상태다. 범위 = 2차 인증 재등록 + 새 복구 코드만(비밀번호 제외). 메일 토큰 모드 2fa → ONB-02부터.
· 강제 모드의 차단 재설정 대기 상태에서는 이 화면 외 모든 콘솔 화면을 막는다. 주소를 직접 입력하거나 뒤로가기로 빠져나가려 해도 이 화면으로 되돌린다. 허용 동작은 로그아웃뿐이고 '‹ 이전으로'(항목 3)는 노출하지 않는다. 세션이 만료돼 재로그인해도 복구 코드가 살아 있으므로 AUTH-01 → 02 → 03 → 이 화면으로 되돌아온다.
· 나가기 자발 모드 = '‹ 이전으로' → 대시보드(DASH-01). 강제 모드 = 나가는 동선 없음. 두 모드 모두 재설정 메일을 보낸 뒤에도 이 화면에 머문다.
· 완료 후 자발 모드 = ONB-01~03 재수행 → 전체 세션 로그아웃 → 로그인(AUTH-01). 강제 모드 = ONB-02~03 재수행 → 재설정 대기 해제 · 세션 생성 → 대시보드(DASH-01)(완료 안내 배너).
1
재설정 안내문 (표시 전용)
값 발송 대상으로 {담당자 이메일}을 표시한다. 이메일 변경 화면은 만들지 않는다.
문구 분기 진입 모드에 따라 본문을 바꾼다. 자발 모드는 "비밀번호 재설정과 2차 인증 재등록", 강제 모드는 "인증 앱 재등록과 새 복구 코드 발급"으로 쓰고, 강제 모드 첫 문장은 선택이 아니라 필수임을 알리는 "인증 앱을 다시 등록해야 서비스를 이용할 수 있습니다"로 시작한다.
무효화 기존 OTP와 복구 코드는 재등록 완료 시 무효화한다(발송 시점 아님). 강제 모드 안내문에는 "재등록 완료 전까지 현재 복구 코드로 다시 로그인할 수 있습니다"를 넣어 세션이 끊겨도 막히지 않음을 알린다.
[디자인 요청] 시안 '백업코드'를 '복구 코드'로 통일한다. 강제 모드 안내문은 시안에 없다.

2무효화 시점 · 운영 예외
무효화 시점 기존 OTP·복구 코드는 재등록 완료 시 무효화한다. 이메일 미수신이나 중도 이탈에도 로그인 수단이 끊기지 않는다.
링크 만료·미사용 링크는 아무 변화를 만들지 않는다. 재발송 시 이전 링크를 즉시 무효화한다. 재설정 토큰이 만료·재사용이면 ONB-04로 보내되 재설정용 문구를 쓴다("만료되었거나 이미 사용된 링크입니다. 다시 로그인해 재설정 메일을 받아 주세요").
강제 모드 세션 만료 유휴 {정책값 15분}·최대 {정책값 8시간}으로 세션이 끊겨도 복구 코드가 아직 살아 있으므로 AUTH-01 → 02 → 03으로 다시 들어와 이 화면으로 복귀한다. 재설정 대기는 재로그인해도, 계정 잠금이 해제돼도 유지된다.
링크를 다른 기기에서 연 경우 재등록을 마친 그 컨텍스트에 세션을 만들고 DASH-01로 보낸다. 계정당 1세션이므로 원래 기기의 세션은 종료된다(다음 요청 때 AUTH-01).
전면 분실 복구 코드까지 없으면 관리자 본인확인 후 초대 재발송으로 처리한다(AUTH-01 상세 8과 동일 프로세스). [확인필요: ADM-04 활성 계정 행에 [초대 재발송]이 없어 화면상 실행 경로가 없다]
