[재설정 메일 발송] 버튼필수
발송 ONB-00 초대 재발송 양식을 재사용한다. 링크는 1회용이고 유효기간은 초대 링크와 같다.
재발송 이전 미사용 링크를 즉시 무효화해 최신 1개만 유효하게 둔다. 쿨다운 {정책값}.
기록 발송 이력을 감사기록에 남긴다. 발송 후 세션은 유지하고 로그아웃은 재등록 완료 시점(ONB-03 [확인])이다.

1진입 경로 · 재설정 흐름
흐름 발송 → 이메일 링크(ONB-00 방식) → ONB-01~03 재수행 → [확인] 시 새 복구 코드 발급 · 이전 코드 폐기 · 기존 세션 전체 로그아웃 → AUTH-01 재로그인.
앱 분실 복구 코드로 로그인(AUTH-01 2단계)한 뒤 이 화면에서 재설정한다.
2무효화 시점 · 운영 예외
무효화 시점 기존 OTP·복구 코드는 재등록 완료 시 무효화한다. 이메일 미수신이나 중도 이탈에도 로그인 수단이 끊기지 않는다.
링크 만료·미사용 링크는 아무 변화를 만들지 않는다. 재발송 시 이전 링크를 즉시 무효화한다.
전면 분실 복구 코드까지 없으면 관리자 본인확인 후 초대 재발송으로 처리한다(AUTH-01 상세 8과 동일 프로세스).
