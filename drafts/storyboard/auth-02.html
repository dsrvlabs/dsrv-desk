2복구 코드 규격
형식 단일 코드 1개, 영숫자 24자(4자×6그룹, 표시 시 " - " 구분), 1회용, 해시 저장. 사용·실패를 감사로그에 남긴다.
사용 후 복구 수단이 없어지므로 DASH-01 권고 배너로 DASH-03 재설정을 유도해 새 코드를 발급하고 이전 코드를 폐기한다.
전면 분실 복구 코드까지 없으면 관리자 본인확인 후 초대 재발송으로 처리한다.
입력 UI 6칸이 아니라 텍스트 필드를 쓴다(항목 2). [디자인 요청]
