2복구 코드 인증 분리
화면 복구 코드 입력·검증·규격은 복구 코드로 인증(AUTH-03)에 있다. 이 화면은 6칸만 둔다(같은 카드 안에서 6칸 ↔ 텍스트 필드로 바꾸는 방식은 폐기).
이어지는 것 AUTH-02 ↔ AUTH-03을 오가도 사전 인증 상태와 통합 카운터는 하나로 이어진다. 두 화면 실패를 합산해 {정책값 5회}에서 잠근다.

· 실패 카운트 계정 단위 통합 카운터 — 비밀번호·인증 코드·복구 코드 실패를 합산하고 로그인 성공 시 0으로 되돌린다. {정책값 5회} 도달 시 계정 잠금이며 잠금 배너는 AUTH-01에 띄운다. [확인필요: 합산 카운터 vs 단계별 개별 카운터]
