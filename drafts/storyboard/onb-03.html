상세내용
1복구 코드 취급
형식 단일 코드 24자(4×6), 1회용, 해시 저장. 인증 앱 분실 시 AUTH-01 2단계에 입력한다.
사용 후 사용 즉시 폐기하고 DASH-01 권고 배너로 DASH-03 재설정을 유도해 새 코드를 발급한다.
이탈 [확인] 전 이탈이면 재개 시 같은 코드를 다시 보여준다.
3완료 이후 상태
상태 전이 계정 상태를 ADM-03 기관·가입자 관리에 반영하고 토큰을 소멸시킨다.
로그인 자동 로그인 없이 AUTH-01 정상 로그인 1회로 등록을 검증한다.
DASH-03 재수행 [확인] 시점에 기존 세션을 전체 로그아웃하고 이전 복구 코드를 폐기하며 비밀번호도 새로 설정한다.
