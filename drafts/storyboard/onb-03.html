복구 코드 · 보관 경고 (표시 전용)
· 클릭 요소 없음 · 카드 머리글 "복구 코드 저장" · 부제 "2FA 앱을 분실했을 때 사용하는 코드입니다" · 경고 칩 "아래 코드를 안전한 곳에 보관하세요. 재발급이 불가합니다."(시안 문구)
· 형식(2026-09-02 확정 · 시안 반영): 단일 코드 1개 · 영숫자 24자 · 4자×6그룹(" - " 구분 표시 · 예 3G56 - SYN5 - YVT9 - DT68 - 5DDR - 14QD) · 1회용 — 종전 8자리×6개 폐기 · ONB-02 검증 성공 시 생성
· 사용처 = 로그인(AUTH-01) 2단계 '복구 코드로 인증'(AUTH-01 항목 5) · '재발급 불가' = 이 화면 이탈 후 재열람 불가 + 코드 자체 재발급 없음 — 새 코드는 DASH-03 재설정(ONB-01~03 재수행) 완료 시에만 발급되고 이전 코드 폐기
· 재진입(재개 · '이전으로' 후 복귀) 시 [확인] 전이면 동일 코드 재표시 · 저장 방식 = 비밀번호와 동일한 해시(원문은 화면 표시용으로만 생성)
