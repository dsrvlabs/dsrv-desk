거래의향 리스트필수
· 목록 컬럼: 교환코인 · 보내는 수량 · 받는 수량 · 비율 — DASH-01 거래 목록과 표기 통일, 비율은 {받는코인}/{주는코인}(notation 규칙)
· 사자/팔자 구분 없음 — 거래의향은 교환 수량 쌍("A코인 X개 ↔ B코인 Y개")으로 표기
· 필터·정렬·페이징 없음 — 전체를 최신순 단일 리스트로 나열
· 타사 게시 행 선택 시 신청하기(BRK-03), 내 게시 행 선택 시 내 게시 상세(BRK-06) 진입
· 시세변동 중지 RFQ · 유효기간(기본 30일) 만료 게시는 리스트에서 제외 — 중지 상태 배지·표시 없음
· 자동 매칭/자동 체결 없음
근거 F-1b · 09 §0 line 57(시세변동 중지) · V2 — 시장개설 아님

상세내용
1시세변동 중지 = 보드 제외
· 게시 시점 대비 시세 변동이 중지 기준을 넘으면 RFQ 자동중지 → 보드 리스트에서 즉시 제외 + 게시자 알림
· 중지 기준·판정은 내부 정책으로 운영 — 화면에 중지 상태·기준 미표시
· 리스트에서 빠지면 신청(BRK-03) 진입 자체가 차단되므로 이후 화면에 중지 상태 표시 불요
· 재개는 게시자 재게시(게시 시점 스냅숏 재산정) · 게시자가 직접 내리는 회수는 BRK-06 [게시 내리기](자동중지와 별도 경로)

3빈 상태 (공통 UI 규격)
· 게시가 0건이면 표 대신 빈 상태 문구: "게시된 거래의향이 없습니다" + 다음 행동 1줄 "[+ 거래의향 등록]으로 첫 거래의향을 올릴 수 있습니다"
· 내 게시가 리스트에 있으면 행 우측 '내 게시' 배지 [확인필요: 배지 표기 방식]
비고
· 마목(당사자 간 중개) 진입점. [방어 핵심] 거래 안전성 검증·KYC담보·정산연계·수수료 4요소를 갖춰 "단순 게시판"이 아님을 소명 — 자동 매칭·자동 체결·시장가 형성은 하지 않음. 필터·정렬·페이징이 없는 단순 나열 구조 자체가 자동 매칭·조건 검색 부재의 담보.
