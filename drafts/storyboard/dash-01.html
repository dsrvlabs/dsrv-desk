1KYC 상태 → 배너 매핑
· ADM-03 기관 KYC 상태: 활성(배너 없음) / 심사중(EDD)·일시제한·동결(배너 노출) — 상태 라벨은 states.html 도메인 상태와 동일 [확인필요: 상태별 문구 차등 여부]
· 행위 화면(EXC-01·BRK-02·BRK-03)과 동일 문구·규격으로 노출 — 종전 "요약 배너" 별도 문구 안(EXC-01 상세 7)은 동일 규격으로 확정
· 이 화면에서는 차단 대상 조작 요소가 없으므로 배너만 노출(버튼 비활성 없음)
3통합 거래 뷰 · 집계 정의
· 나목(DSRV 상대 교환)과 마목(당사자 중개)을 한 화면에서 상태별로 요약 · 카드 3종은 상태 enum(상세 5)의 그룹 합계
· 대기 = 고객 행동 또는 상대 행동을 기다리는 상태(나목 수락 대기 · 마목 신청 대기·수락 대기) / 진행 중 = 확정 후 집행 대기(나목 DSRV 거래 진행 약 2영업일 · 마목 이전 진행) — 내부 승인 단계는 'DSRV 거래 진행중' 하나로만 노출(EXC-03)
4행 클릭 분기 — 판별 키
· 분기 키 = 구분(나목 교환 / 마목 게시 / 마목 신청) × 상태 칩 — 두 열만으로 목적지가 하나로 정해짐(종전 '승인 대기' 3종 라벨로는 BRK-06/07 판별 불가 → 구분 3값·도메인 상태 라벨로 해소)
· 마목 '협의중'은 게시자(BRK-06 → BRK-04 수락/거절)와 신청자(BRK-07 수락 대기)가 같은 라벨 — 구분 열로 판별
· 마목 '중지'(price guard 자동중지): 게시자 → BRK-06(재개는 재게시) · 신청자 → BRK-07(신청 자동 종결 · 양측 이메일)
5상태 칩 매핑 표
· 나목 — 요청됨: 대기(파랑) → EXC-02 / 비율 제시: 대기(파랑) → EXC-02 / 진행 중: 진행(노랑) → EXC-03 / 완료: 완료(초록) → EXC-04 / 보류: 진행(노랑) → EXC-04(DSRV 심사 후 보류 — 보류 배너 노출) / 거절: 종결(회색) → EXC-04(고객 거절) / 만료: 종결(회색) → EXC-04(EXC-02 유효기간 경과)
· 마목 — 게재중: 대기(파랑) → BRK-06 / 협의중: 대기(파랑) → 게시자 BRK-06(→BRK-04) · 신청자 BRK-07 / 확정: 진행(노랑) → BRK-05 / 완료: 완료(초록) → BRK-05 / 회수: 종결(회색) → 게시자 BRK-06 · 신청자 BRK-07 / 중지: 종결(회색) → 게시자 BRK-06 · 신청자 BRK-07
· 신청자 측 종결(신청 거절 · 신청 만료): 종결(회색) → BRK-07 [확인필요: enum 추가]
