오류 안내 (표시 전용)
노출 초대 링크 토큰이 유효하지 않을 때 이 화면으로 보낸다 — 만료(발송 + 72시간 경과)와 이미 사용됨(활성화 완료로 소멸)을 구분하지 않고 같은 문구를 쓴다.
문구 고정 2단 — 칩 "⚠ 이 초대 링크는 사용할 수 없습니다" + 본문 "만료되었거나 이미 사용된 링크입니다. 관리자에게 초대 재발송을 요청해 주세요."
노출 금지 만료인지 사용된 것인지, 계정이 이미 활성인지 알려주지 않는다.
근거 ISMS 2.5(인증정보 관리) · 09 §0 결정(2026-09-02) 오류 케이스 통합
2
문의 안내 (표시 전용)
노출 항상 보인다.
값 문의 주소는 ONB-00 발신 주소와 같은 값을 쓴다(단일 출처). 주소는 텍스트로만 두고 mailto 링크를 걸지 않는다.
근거 notation 이메일 통지 · ONB-00 항목 1
상세내용
1토큰 케이스 통합
통합 대상 만료(A)와 이미 사용됨(B) 두 경우를 화면 하나·문구 하나로 처리한다. 종전 ONB-01 배너 2종과 [로그인 화면으로] 조건부 노출은 폐기한다.
이 화면에 오지 않는 경우 활성화 미완료 상태의 재클릭은 재개로 처리해 ONB-01·02·03 중 진행 중 화면으로 라우팅한다.
재발급 ADM-03 초대 재발송으로만 한다(새 토큰 발급 · 이전 토큰 즉시 무효 · 진행 상태 초기화).
조작 요소 두지 않는다 — 계정이 이미 활성이어서 로그인하려는 경우도 이용자가 직접 로그인 화면에 접속한다.
통합 이유 분기 화면·문구를 두지 않아 구현이 단순하고, 토큰이 만료인지 사용된 것인지를 알려주지 않는다.
비고
· 초대 링크(ONB-00)를 눌렀을 때 토큰이 유효하지 않으면 진입하는 종결 화면. 2026-09-02 사용자 결정으로 신설 — 종전에는 ONB-01 항목 1의 배너 2종(만료·사용됨)으로만 정의돼 있었다.
· 확정(구현 단순 우선) — 만료·사용됨 단일 문구 · 재발급 링크 없음(관리자 요청) · [로그인 화면으로] 버튼 없음 · mailto 없음. 조작 요소가 없는 화면이다.
· [디자인 요청] Figma 시안 없음 — ONB-01~03과 같은 로그인 전 레이아웃으로 기획 유지.
· 종결 화면 — 이 화면에서 다른 화면으로 가는 버튼·링크를 두지 않는다(2026-09-02 사용자 결정). 재발급은 관리자 요청, 로그인은 이용자가 직접 접속한다.
