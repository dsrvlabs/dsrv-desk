브랜드 패널 (로고 'DSRV' · 태그라인 · 소개문)클릭무반응. 표시 전용이다. 로그인 전 화면이라 상단 메뉴(GNB)와 기관 배지가 없다.
푸터 '개인정보처리방침' / '이용약관'클릭각 문서 페이지를 새 탭으로 연다. 대상 URL [확인필요] · 이용약관·개인정보처리방침이 가입 시 동의한 문서와 같은 문서인지 [확인필요]
브라우저 뒤로가기전 화면 미지원"접근할 수 없는 화면입니다" 안내 후 이동한다. 로그인 전 화면(ONB-01~04 · AUTH-01·02)에서는 로그인(AUTH-01) 1단계로, 로그인 상태 화면(DASH-02·03)에서는 대시보드(DASH-01)로 간다.
· 이 프레임(왼쪽 브랜드 패널 + 오른쪽 카드 + 푸터)은 ONB-01·02·03·04 · AUTH-01·02 · DASH-02·03이 같이 쓴다. 프레임 동작은 이 화면에만 적고, 나머지 화면에는 이 화면과 다른 점만 적는다.
· 진입 초대 메일(ONB-00)의 링크 클릭. 링크의 토큰을 진입 시 1회 검증해 정상이면 이 화면을 열고, 만료되었거나 이미 사용된 토큰이면 초대 링크 오류(ONB-04)로, 비밀번호까지 저장된 토큰이면 진행 중인 단계(ONB-02 또는 ONB-03)로 보낸다. 2차 인증 재설정(DASH-03)에서 보낸 메일의 링크도 같은 방식으로 이 화면에 들어온다.
· 이 화면과 ONB-02·03의 브랜드 패널에는 'DSRV 서비스 소개 보기 →' 링크가 없다. 활성화 도중 외부로 나가는 동선을 두지 않는다.
1
새 비밀번호 입력필수
입력 가능 항상 가능하다. 토큰이 유효하지 않으면 이 화면 자체가 열리지 않는다.
허용 문자 영문 대·소문자 · 숫자 · 특수문자 !@#$%^&*()만 받고 그 외 문자는 입력 시점에 무시한다. 길이는 8~20자로, 20자를 넘는 입력은 받지 않는다.
검증 입력 중에는 판정하지 않는다. [다음] 클릭 시 입력된 값 전체를 대상으로 규칙 ①~④(조합 3종 이상 · 8~20자 · 이메일 @ 앞부분과 동일 금지 · 동일 문자 반복 금지)를 클라이언트가 한 번에 판정한다. 서버는 규칙을 다시 검증하지 않는다.
실패 빈칸이면 인라인 ⚠ "값을 입력해 주세요", 규칙 미충족이면 인라인 ⚠에 위반한 규칙을 문구로 보인다. 입력값은 유지하고 화면에 머문다.
연동 없음. 판정은 모두 [다음] 클릭 시 한다.
저장 단방향 해시와 salt로만 저장한다.

연동 없음. 항목 1을 고쳐도 다시 비교하지 않는다(제출 시 판정).

노출 항상 보인다.
클릭 가능 항상 활성이다. 처리 중에만 비활성으로 두어 중복 클릭을 막는다. Enter 키도 같이 처리한다.
확인 사항 클릭 시 클라이언트가 두 필드를 한 번에 검사한다 — ① 빈칸 ② 새 비밀번호 규칙 ①~④ ③ 확인 값 일치. 문제가 있는 필드마다 인라인 ⚠를 동시에 보이고 서버 요청을 보내지 않는다. 모두 통과하면 요청한다. 확인 다이얼로그는 없고 서버가 규칙을 다시 검증하지도 않는다.
액션 비밀번호를 저장하고 계정 상태를 '활성화 진행 중'으로 기록해 재개 지점을 만든 뒤 ONB-02로 넘긴다. 활성화 중 비밀번호를 다시 바꾸는 동선은 만들지 않는다.
