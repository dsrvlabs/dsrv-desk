· 검증 시점: 키 입력마다 규칙 ①~④를 판정해 항목 4 안내문의 각 항목 표시를 ○(미충족·회색) → ✓(충족·초록)으로 갱신 · 포커스 아웃 시 미충족 항목이 남으면 빨간 테두리 + 필드 아래 인라인 ⚠ "비밀번호 규칙을 확인해 주세요"
· 상태 ① 빈칸(기본 · 라벨 "새 비밀번호 *" · 안내 "비밀번호 입력") ② 입력 중(규칙 표시 실시간) ③ 규칙 위반(포커스 아웃 · 빨간 테두리 + ⚠) ④ 통과(테두리 정상 · 안내문 ✓ 4개) ⑤ 비활성(항목 1 토큰 오류 시)
· 규칙 수치(3종·8자·4번)는 {정책값} — 출처 AUTH-01 비고 [비밀번호 규칙] · ADM-03 파라미터 아님 [확인필요: 고정 규칙 유지 vs 관리자 설정값] · 값 변경 시 확인 필드(항목 3) 재검증
· 원문 저장·전송 없음(단방향 해시+salt) · 같은 안내문구를 비밀번호 변경(DASH-02)에서도 재사용

새 비밀번호 확인 입력필수
· 마스킹 · 허용 문자 = 항목 2와 동일 · 붙여넣기 허용
· 검증 시점: 키 입력마다 항목 2 값과 일치 비교 · 불일치 표시는 포커스 아웃 시(입력 도중 깜빡임 방지) · 항목 2 값이 바뀌면 즉시 재비교
· 상태 ① 빈칸(기본 · 라벨 "새 비밀번호 확인 *" · 안내 "비밀번호 재입력") ② 일치(테두리 정상 · 필드 우측 ✓) ③ 불일치 — 빨간 테두리 + 필드 아래 인라인 ⚠ "비밀번호가 일치하지 않습니다" ④ 비활성(토큰 오류)
· 항목 2가 규칙 위반 상태여도 비교는 수행(두 경고 동시 노출 가능)
