DSRV 교환·중개 서비스 — 화면기획 스토리보드

법인 고객이 DSRV Desk(고객 콘솔)에서 가상자산을 교환하거나, 다른 고객과의 교환을 게시판에서 중개받는 서비스의 화면 24개를 정리한 문서입니다. DSRV Admin(관리자 도구) 2개 화면도 포함합니다. 자동 체결·오더북은 없고, 모든 자산 이전은 담당자 승인 후 콜드 지갑에서 사람이 집행합니다.

1서비스 두 가지 — 무엇이 다른가

나목 · 교환고객 ↔ DSRV 직접 교환
고객이 가진 자산을 DSRV의 교환 재고와 바꿉니다. 상대방은 항상 DSRV입니다.
  • 고객이 교환하기에서 수량을 넣으면 시스템이 비율을 제시하고, 고객이 수락하면 요청이 확정됩니다.
  • DSRV 담당자가 어드민에서 건별로 승인하고, 커스터디팀이 콜드 지갑에서 수동 집행합니다. 자동 체결은 없습니다.
  • 별도 수수료 없이 스프레드에 비용이 들어 있고, 가스비는 받는 수량에서 차감합니다.
마목 · 중개고객 ↔ 고객 교환을 게시판으로 중개
한 고객이 조건을 게시하고 다른 고객이 신청합니다. DSRV는 가격을 정하지 않고 검증·예치·인도·기록만 합니다.
  • 게시자가 신청을 수락하면 즉시 확정됩니다. 역제안·협상 기능은 없고, 게시 1건에 동시 신청은 1건입니다.
  • 확정 후 양측이 보내는 자산을 에스크로 전용지갑에 예치 → 양건 확인 → 각 상대방에게 인도합니다. 한쪽만 이전되는 일이 구조적으로 없습니다.
  • 중개 수수료는 거래액 1%를 양측이 각자 부담하고, 자산 수량에서 빼지 않고 별도 정산합니다.
