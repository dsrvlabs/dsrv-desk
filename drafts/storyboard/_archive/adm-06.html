ORG 목록·KYC 상태 관리필수
· ORG별 KYC 상태(활성·심사중·일시제한·동결·해지)·재이행 도래일 표시
· CDD/EDD 탈락 시 가입 거절 + 사유 기록, 거래거절 건 STR 검토 연계(예외 A1)
· 재이행 기한 초과·미응답 → 신규 거래 제한(예외 A6)
근거: 관리자 콘솔 ORG·KYC 통합 [F-12] · 예외케이스 A1·A2·A6 (28 §A)
2
멤버·계정 조치 (잠금 해제·초대 재발송)필수
· 계정 잠금(로그인 5회 오류, AUTH-01) 건을 여기서 처리 — 본인확인 후 해제 또는 초대 재발송
· 초대 재발송 = 기존 ONB-00 플로우 재사용(신규 개발 없음), 백업코드 분실·소진 케이스도 동일 버튼
· 잠금·해제·재발송 이력은 감사로그 기록
근거: 비정상 로그인 통제 · 정보보호 관리체계(ISMS) 인증기준 2.5(인증)·2.6(접근통제)
3
초대 발송 (온보딩 진입점)필수
· 고객사 담당자 이메일로 초대 발송 → ONB-00(초대 이메일) → ONB-01(활성화·2FA)
· 링크 72시간·1회 유효 — 만료 시 이 화면에서 재발급
· 담당자 2인(기안↔승인 분리) 미확보 시 온보딩 진행 불가(예외 A3)
근거: 직무분리 2인 요건 · 정보보호 관리체계(ISMS) 인증기준 2.2.2 · 예외케이스 A3
4
계정 상태 전이·재이행 트리거필수
· 상태 기계: 심사중 → 활성 → 일시제한(재이행·의심) → 동결(제재) → 해지
· 실소유자·지배구조 변경 등 이벤트 트리거 시 수시 CDD 재이행 → 재심사 중 거래 제한(예외 A4)
· 해지 시에도 기록은 15년 보존(예외 A5)
근거: 고객확인 재이행 [L1 §5의2] · 기록 보존 [L6 §9] · 예외케이스 A4·A5
온보딩 예외 귀속
· A1 CDD/EDD 탈락 → 거절 + STR 검토
· A2 심사 장기화 → '심사중' 유지(고객 측은 조회만)
· A6 재이행 미응답 → 일시제한
· [확인필요] 일시제한 중 조회·출금 허용 범위
계정 잠금 해제 절차
· AUTH-01 잠금 발생 → ADM-02 알람함 알림 → 이 화면에서 조치
· 본인확인(유선·등록 이메일) → 해제 or 초대 재발송
· 처리자·시각·사유 감사로그 — 운영 프로세스이며 별도 승인 단계 없음
해지(탈퇴) 흐름
해지 요청 → 진행 중 거래 완결 대기 → 자산 전량 출금 확인 → 비활성화
· 신규 거래는 요청 즉시 차단
· 거래·AML 기록은 법정 기간 보존(거래 15년·AML 5년)
비고
· DSRV 내부 관리자 화면(고객사 노출 없음). 관리자 메뉴 'ORG·KYC' 탭 — 예외케이스 A1~A6(온보딩)과 계정 잠금(AUTH-01)의 처리 귀속 화면.
· [최소 구현] 초대 발송·재발송은 기존 ONB-00 플로우 재사용(메일 템플릿·활성화 링크 동일), 잠금 해제는 운영 프로세스(본인확인) + 버튼 — 신규 개발은 목록·버튼 수준.
· KYC 심사 자체(서류 검토·EDD)는 별도 AML 시스템 영역 — 이 화면은 상태 조회·전이와 계정 조치만 담당. [확인필요] KYC 심사 도구와의 연동 범위.
· 연결: 초대 발송 → ONB-00 · 잠금 알림 수신 ← ADM-02 알람함 · 계정 상태는 전 화면 게이팅(G-3)의 단일 출처
