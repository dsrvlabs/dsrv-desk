확정 거래 내역 — 공통 포맷 (표시 전용)
구성 7행 고정 — 게시번호 · 교환쌍·방향 · 보내는 수량 · 받는 수량 · 비율 · 거래 상대방 · 확정 일시.
기준 교환쌍·방향과 보내는 수량·받는 수량은 화면을 보는 고객 기준으로만 적는다(2026-09-04 변경 · 종전 게시자 기준 2행 + '내 기준' 1행 폐기). 라벨은 '보내는 수량'·'받는 수량'이고 "(게시자)"·"(신청자)" 같은 부기를 두지 않는다. 게시자 콘솔에서는 게시 조건과 같은 방향, 신청자 콘솔에서는 역방향 값이 들어간다(목업은 신청자 콘솔 예시 · 상대방 수량은 표시하지 않는다). 항목 3 이전 지시와 항목 4 수수료의 기준 수량은 이 화면의 보내는 수량이다. 비율은 게시 조건의 값을 그대로 쓴다.
상대방 확정으로 마스킹을 해제한 상호 전문과 역할을 적는다. 확정 일시는 게시자 [수락] 시각이다(YYYY-MM-DD HH:MM).
자릿수 ETH 4 / USDC·USDT 2, 비율은 스테이블 페어 4자리와 ETH 페어 {스테이블}/ETH 2자리.
상태 로딩은 "불러오는 중…"이고 3초 초과 시 상단 배너와 값 "—"로 넘기되 [확인]은 활성으로 남긴다.
수수료 이 블록의 보내는·받는 수량은 게시 조건 그대로의 거래 수량이고 수수료를 반영하지 않는다 — 라벨에 "세전/세후" 부기를 두지 않는다. 수수료를 더한 실제 예치 수량은 항목 3 예치 행에서 본다(2026-09-04 결정).

예치·인도 상태 · 완결성 · 트래블룰 (표시 전용)
구성 6행 고정 — ① 내 예치(나 → 에스크로 전용지갑) ② 상대 예치(상대 → 에스크로 전용지갑) ③ 예치 완결성 ④ 내 인도(에스크로 전용지갑 → 나) ⑤ 트래블룰 ⑥ 발생 가스비. 상대 앞 인도 행은 두지 않는다(상대측 수령 정보 미노출).
①② 값 「예치 대기 · 다음 정산 배치 편입」 / 「예치 진행 · {배치 일시}」 / 「예치 완료 · {일시}」(초록) / 「반환 완료 · {일시}」(이전 중지 시) 중 하나. 라벨에 '에스크로 전용지갑' 명칭은 쓰되(약관 제3조 8호 용어와 화면 용어 일치) 지갑 주소·tx 해시·회계 계정명·시세 소스명은 넣지 않는다.
③ 완결성 「양건 예치 확인 대기」 → 「양건 예치 확인 완료 · {일시}」. 두 예치가 모두 에스크로 전용지갑에 들어와 대사가 끝난 뒤에만 인도가 생성된다 — 한쪽만 이전되는 상황을 구조로 막는다(역이전 없음). 확인이 실패하면 보류 상태로 둔다.
④ 값 「인도 대기 · 양건 예치 확인 후」 / 「인도 대기 · 다음 정산 배치 편입」 / 「인도 진행 · {배치 일시}」 / 「인도 완료 · {일시}」(초록) / 「이전 보류」 중 하나.
⑤ 트래블룰 「양측 송·수신인 정보 확인 중」 → 「확인 완료」. 미완료면 완결성 확인을 대기 상태로 유지하고 사유 문구는 일반화한다.

내 중개 수수료 (표시 전용)
값 수수료율은 {정책값 1.00%}(ADM-03 · 거래액 기준 고정)이고 양 당사자가 각자 부담한다. 기준은 각자 보내는 자산 수량(항목 1 보내는 수량 행)이며 각 자산 자릿수로 절사한다. 수수료를 포함한 수량을 예치한다 — 내가 보내는 798.40 USDC에 수수료 7.98 USDC를 더한 806.38 USDC가 에스크로 전용지갑으로 나가고(게시자는 800 + 8.00 = 808 USDT), 인도할 때는 상대가 보낸 거래 수량에서 가스비만 뺀 만큼을 받는다. 수수료는 에스크로에 남았다가 정책 주기 배치로 DSRV 운영 지갑(수수료풀)에 옮겨진다(2026-09-04 결정 · 어드민 ADM-02 ② 수수료 스윕 행). 정산 확정 시점은 인도 집행 시점이다(2026-09-03(15)). 고객 화면에는 스윕을 표시하지 않는다.
노출 범위 자기 측 금액만 보여주고 상대측 금액과 회계 계정명(중개수익)은 넣지 않는다. 구분회계는 ADM-02 CSV에서만 본다. 거래보고서·영수증은 발급하지 않는다.
발생 가스비 내 예치 1건과 내 앞 인도 1건, 2회분의 실발생 가스비를 각각 ETH 4자리로 적고 합계를 받는 자산 환산액으로 보여준다(예 예치 0.0019 ETH + 인도 0.0019 ETH = 0.0038 ETH → 11.92 USDT 차감). 합계가 실제 차감액이며 인도 수량(받는 수량)에서 뺀다. BRK-02·03·04의 예상 가스비(2회분)는 참고 안내였고 상한이 아니다. 아직 집행되지 않은 건은 "— 예치 시 확정" / "— 인도 시 확정". 상대측 가스비는 보여주지 않는다.
