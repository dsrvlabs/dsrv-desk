· 계정 상태(가입자)는 이 시스템 것이다 — 잠금·해제는 ADM-02 T8, 탈취 의심은 '잠금 유지·이관'(기관 상태를 이 시스템이 바꾸지 않으므로 커스터디에 통보해 판단을 맡긴다).

· DSRV 내부 관리자 화면(고객사 노출 없음). 어드민은 홈(ADM-02)·설정(ADM-03) 2화면.
· 목업 인터랙션(2026-09-02): 어드민 프레임 폭을 다른 화면의 1.5배(810px)로 넓히고, 드롭다운(취급자산 상태 ▾)을 목업에서 실제로 펼칠 수 있게 함(바깥 클릭·ESC = 변경 없이 닫힘 · 2026-09-07 [상태 변경 ▾] 삭제로 1종). 확인 다이얼로그가 필요한 선택(중지)은 값을 바꾸지 않고 다음 단계를 노란 배지로 표시 — 다이얼로그·사유 모달 자체는 항목 설명 기준. 관리 메뉴 '홈' 클릭 시 ADM-02로 이동.
· [긴급대응 전용 플래그 없음] 모든 집행이 사람의 승인·서명을 거치는 구조 — 승인을 멈추면 집행도 멈춤. 별도 '거래정지·긴급출금중단' 버튼 없이 승인 중단 + 사고대응 절차서로 대응 — 근거: ISMS 2.11.1(사고 대응·복구). 취급자산 '중지'는 자산 단위 신규 요청 차단이며 긴급정지 플래그가 아님.
· [화이트리스트 미사용] 교환·중개는 내부 지갑 간 이전이라 외부 주소를 다루지 않는다. 화이트리스트는 이 시스템 전체에서 쓰지 않는다(2026-09-04 사용자 결정) — 이 콘솔에 설정 항목도 두지 않는다.
· [핫월렛 비중 임계 삭제] 핫월렛이 없어(09 §0) 항목이 성립하지 않는다. 콜드 서명 장애도 커스터디가 집행 성공까지 책임지는 영역이라 어드민 알림 유형에 두지 않는다(2026-09-04 결정 · 종전 T6 삭제).
· 연결: 초대 발송 → ONB-00 · 정책값 표출 EXC-01/02·BRK-02/03/04/07 · 발생 알림 처리(계정 잠금·시세 중단·재고 부족·대사 불일치)는 홈(ADM-02) ④ 운영 알림 · 기관 KYC 상태 = 전 화면 게이팅(G-3) 단일 출처 — 값은 커스터디 조회(상세내용 12)
· 2026-09-07(22) 커스터디 연동 확정: 기관 상태는 커스터디 customerStatusCd 6종을 조회 API로 읽는다(변경 웹훅 없음 · 관문마다 조회). 이 화면의 [상태 변경 ▾]와 종전 5종 라벨을 삭제하고 항목 12를 표시 전용 칩으로 바꿨다. 거래 위험은 커스터디가 진행 불가 건만 웹훅(거래 건 번호)으로 알린다 — 홈(ADM-02) 항목 8.
· KYC 재이행은 오프라인(커스터디) 업무이고 이 콘솔은 결과만 기관 상태로 받는다 — 재이행 도래일 알림·처리함 행을 두지 않는다(2026-09-04 결정 · 종전 T7 삭제). 아래 재이행 주기 표기는 커스터디 정책을 참고로 적은 것이다.
· 2026-09-02 설명 형식 개정 적용(핀 = 조작 요소 단위) — 파라미터는 그룹 단위 핀(입력 규격 명시), '페어별' 스프레드 프레임을 3페어 입력 3개로 수정, 취급자산 상태·정책 버전 라인·dirty 표시 추가, 조치 열 '—' 제거([상태 변경 ▾] 전 행), 저장 = 확인 없음 / 자산 중지·KYC 상태 변경 = 확인 다이얼로그로 통일 · 서비스명 DSRV Admin.
· 2026-09-04(19) 설정 화면 정리(사용자 결정): ① 입력칸에는 값만 넣고 단위는 칸 밖에 둔다 ② 나목 교환 자산풀 수량 표시 신설 — 표시 전용이고, 담당자가 교환 재고 지갑에 넣으면 인덱서가 노드에서 읽어 자동 반영한다(어드민 입력·보정 기능 없음) ③ 시세(외부지표) 소스 선택 칸 삭제 — 소스 자체는 계속 쓰지만 이 화면에서 고르지 않는다(용도·환산 경로는 상세내용 7) ④ 핫월렛 비중 임계 삭제(핫월렛이 없어 항목이 성립하지 않는다) ⑤ [되돌리기] 삭제 — 저장 버튼은 [변경 저장] 하나다 ⑥ 상태 전이·재이행 영역 삭제 — 상태 기계는 케이스분기 문서가 정본이고, 게이팅·해지 흐름은 상세내용 12로 옮겼다.
