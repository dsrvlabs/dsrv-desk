상세내용
1접근 전제
· 초대받은 ORG 담당자만 계정 보유(셀프가입 없음)
· KYC·계약 완료 전에는 로그인 후에도 기능 게이팅(G-3 배너)
2MFA 적용 범위
· 로그인 시 1회 + 승인·정책변경 등 민감행위를 할 때 다시 인증
· 정보변경 시 다시 인증하는 대상 = 계정정보(비밀번호·2차 인증·세션·기기, DASH-01) — 화이트리스트 등록은 교환·중개에 없으므로 대상에서 제외
· 인증 실패·우회 시도는 감사기록에 남김 — 근거: 정보보호 관리체계(ISMS) 인증기준 2.10.4(중요정보 변경 시 재인증)
3세션 이후 흐름
· 로그인 성공 → 대시보드 → 교환하기(나목)·교환게시판(마목) 탭 진입
· 유휴 타임아웃 시 자동 로그아웃·재인증
4잠금 해제·알림 처리
· 잠금 해제: DSRV 관리자가 본인확인 후 해제 또는 초대 재발송 — 처리는 어드민 홈(ADM-02) 처리함의 '계정 잠금' 알람, 백업코드 분실과 동일한 운영 프로세스
· 잠금·해제·알림 이력은 감사로그 기록
