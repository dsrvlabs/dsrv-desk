# 웨이브릿지 vs DSRV — "교환을 하느냐"가 가르는 구조 차이
### (내부 공유용 · 2026-07-06)

## TL;DR
1. **웨이브릿지** = 교환(나목)까지 하는 **딜러형 프라임브로커리지** → 자기가 거래 상대방이 되고 가격을 만든다.
2. **DSRV(이번 설계)** = 교환을 하지 않는 **순수 중개(마목) + 커스터디** → 거래 당사자가 되지 않고 가격에 관여하지 않는다.
3. 2026년 규제 흐름(업비트·코빗 갱신)에서 **매매·교환은 빠지고 중개는 남았다** → DSRV 방향이 규제 순류(順流).

---

## 1. 먼저, VASP 5개 행위유형 프레임
| 목 | 행위 | 성격 | 웨이브릿지 | DSRV |
|---|---|---|---|---|
| 가 | 매도·매수 | 매매(당사자) | (보유 추정) | ✗ |
| 나 | **교환** | 코인↔코인(당사자) | **보유** | ✗ (안 함) |
| 다 | 이전 | 전송 | 보유 | ✅ 보유 |
| 라 | 보관·관리 | 커스터디 | 보유 | ✅ 보유 |
| 마 | **중개·알선·대행** | 남의 매매·교환 연결 | 보유 | 🎯 **이번 신규** |

> 핵심: 웨이브릿지는 **나목(교환)+마목(중개)을 함께** 가졌고, DSRV는 **마목(중개)만** 새로 얹는다.

## 2. "교환을 하느냐"의 진짜 의미
같은 "거래를 도와준다"처럼 보여도 법적으로 정반대입니다.

| | 교환 (나목) | 중개 (마목) |
|---|---|---|
| 내 지위 | **내가 거래 상대방이 된다** ("내가 산다/판다") | 상대를 **붙여준다** (당사자 아님) |
| 가격 | **내가 정해서 제시**(견적·스프레드) | 당사자끼리 협의, 나는 불관여 |
| 자산 | **자기재고**(내 돈으로 산 물량) 사용 | 당사자 자산만 오감 |
| 수익 | 스프레드(가격차) | 중개수수료 |
| 한 줄 | **"내가 상대다"** | **"상대를 찾아준다"** |

→ **교환 = 자기자본으로 시장의 한쪽이 되는 것.** 이게 하느냐 마느냐가 모든 걸 가릅니다.

## 3. 웨이브릿지 구조 (공개정보·기사 기반)
- 포지셔닝: 기관 대상 **프라임브로커리지**(돌핀/Dolfin — "법인 가상자산 교환 및 중개").
- **교환(나목) 보유** → OTC 데스크에서 기관 주문을 **자기 물량/유동성으로 직접 체결**(딜러), **Wave Pricing Engine으로 가격 산출·제시**.
- 즉 에이전시(중개) + **딜러(교환)의 혼합**. 대량 블록딜을 시장충격 없이 소화하려면 이 딜러 기능이 상품성의 핵심.
- 함의: 교환 라이선스가 필수이고, **자기자본·재고·가격결정·시장조성 리스크**를 안고 감.

## 4. DSRV 구조 (이번 중개 단일 설계)
- 보유: **이전(다)+보관·관리(라)** = 커스터디. 신규: **교환 중개(마)만**.
- **거래 당사자·가격결정 주체가 되지 않음.** 오더북·자기재고·스프레드 **없음**. 원화 미취급.
- 결제: 양 당사자 자산이 **모두 DSRV 커스터디**에 있으므로, 확정 시 **커스터디 내부에서 동시 이전(DvP)** — 별도 에스크로도 불필요.
- 수익: **중개수수료만**.
- 즉 **"교환은 하지 않고, 보관·정산·연결만 장악하는 중립 인프라."**

## 5. 핵심 비교표
| 구분 | 웨이브릿지 | DSRV (중개 단일) |
|---|---|---|
| 대표 성격 | 딜러형 프라임브로커리지 | 커스터디 기반 중립 중개 |
| 교환(나목) | **한다** | **안 한다** |
| 거래 지위 | 상대방이 됨(딜러) | 중개인(비당사자) |
| 가격 | 자체 산출·제시 | 당사자 협의, 불관여 |
| 자기재고 | 있음(자기자본) | 없음 |
| 오더북 | (프라임 통합) | 없음 |
| 수익 | 스프레드+수수료 | 중개수수료(1% 안) |
| 자기자본 부담 | 큼(재고·헤지) | 없음 |
| 이해상충 | 딜러+중개 겸함 → 관리 부담 | 구조적으로 적음 |
| 규제 병목 | 교환 유형(진입 어려움) | 중개는 정상 경로 |

## 6. 규제 함의 — 왜 지금 이 차이가 중요한가
- **2026년 업비트·코빗 갱신 시 FIU가 5개 중 3개(이전·보관관리·중개)만 갱신, 매도·매수·교환 2개 제외.** 사유는 "실제 영위 범위만 신고" + 거래소는 자체 트레이딩팀이 없어 자기자본 매매를 안 함. → 거래소는 향후 자기자본 거래주체·OTC·PB 불가. (헤럴드경제 [크립토360], `reference/R1_거래소_유형분리_2026.md`)
- 해석: **매매·교환은 진입·유지가 까다로운 트랙**, **중개는 당국이 문제삼지 않는 정상 트랙**(MiCA식 업권 분리와 유사).
- **DSRV가 교환을 빼고 중개만 가는 것은 규제 순류**이며, 웨이브릿지가 안고 있는 교환(딜러) 리스크를 애초에 지지 않는다.

## 7. DSRV가 "교환을 안 함"으로써 얻는 것
1. **심사 반려 리스크↓** — "사실상 매매·시장조성·자기거래 아니냐"는 심사 공격 포인트(자기재고·스프레드·헤지)가 존재하지 않음.
2. **자기자본 부담 없음** — 재고 매입 자금 불요.
3. **이해상충 구조적 회피** — 웨이브릿지가 스스로 지적한 "거래소+중개 한 몸이라 이해상충" 문제를, 당사자가 되지 않음으로써 안 가짐. (마케팅 메시지로도 강함)
4. **커스터디 강점 재사용** — MPC 키관리·다중승인을 그대로 정산 인프라로. *(단, 콜드월렛 미사용 시 §11 콜드 80% 충족·MPC 콜드 인정 여부는 별도 검토 필요)*

## 8. 유의점 (내부 인지)
- **순수 중개는 실제로 영위해야 유지된다**(형해화 금지) — R1의 "실제 미영위분 제외" 논리.
- **교환쌍 확정(2026-07-06)**: **ETH↔USDC** (Base, 2종). 양측 커스터디 보유분을 내부 동시 스왑.
- **"커스터디 내부 동시이전(DvP)"을 매매가 아닌 중개+이전(다목)으로 볼 수 있는지**는 로펌 검토 대상. `[로펌게이트]`
