## 상태전이 설계에 주는 시사점 (요약)

1. **의향(게시) 상태**: `작성중 → 게시중 → 협의중 → 확정대기(승인중) → 이전중 → 완료` + 이탈: `철회·만료·거절·무산·실효·차단`
2. **이전(정산) 상태**: `대기 → leg1 전송 → leg2 전송 → 완결` + 실패 분기: `재시도 → 롤백 → 운영이관` — **F1(한쪽만 성공)이 상태 기계의 최우선 설계 대상**
3. **계정 상태**: `심사중 → 활성 → 일시제한(재이행·의심) → 동결(제재) → 해지`
4. **잠금 정책(C2)**: 게시/확정 시점의 잔고 잠금 여부가 C·D·E 케이스 전반을 결정 — **가장 먼저 결정할 것**
5. `[결정필요]` 4건: 잔고 잠금(C2) · 1:N 협의 정책(D3) · 확정 후 취소 범위(E5) · 수수료 징수 시점(F7)
