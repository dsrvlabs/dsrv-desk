## 목차 및 섹션별 와꾸

### 1. 회사개요
- 1.1 법인 일반현황 — F1~F9 [근거 1-A]
- 1.2 정관상 사업목적 (디지털자산 수탁·관리업 + **교환·중개업 포섭 정비**)
- 1.6 **본 변경신고 개요**: 기존 (다)이전·(라)보관관리에 **(나)교환 + (마)교환 중개 추가**. 행위유형표(다·라 유지 / 나·마 신규). [근거 L1 §7②, L2 §10의11]

### 2. 사업내용
- **2.1 기본 원칙**: ①원화·금전 미취급 ②국내 법인 한정(단계 확대) ③검증된 커스터디(100% 콜드·수동) 안전장치 확장 ④**나목 교환은 가격형성자가 되지 않고**(외부지표 스프레드·수동집행) ⑤**마목 중개는 당사자가 되지 않음**
- **2.2 현행 사업(커스터디)**: 이전·보관관리 5단계 절차 — 그대로 [근거 F1]
- **2.3 신규 A — 교환(나목)**
  - 2.3.1 정의: 자사 커스터디 법인 고객과 **DSRV가 상대방이 되어 ETH·USDC·USDT 교환**. [근거 L6 §2나목]
  - 2.3.2 **거래소·MM 아님(심사 방어)**: 자체 오더북·자동 호가매칭·자동 체결·자체 시세산정 **없음**. 교환비율 = **외부 지표 참조 스프레드 고정**. **연속 양방향 호가 금지 → 단건 RFQ·블록딜만**. **API 자동체결 금지·수동 승인/타임딜레이**. UI에 **'공식 LP·마켓메이커·플랫폼 보증' 라벨 금지**(평판 뱃지로 대체). 집행은 건별 수동, 재고는 최소 한도·콜드 보유.
  - 2.3.6 **이해상충 통제(단일법인 차이니즈월)** *(핵심)*: 마목 게시판 운영과 나목 상대방 겸업의 self-dealing 방지 — ⓐ **정보격리(blind wall)**: 나목 교환 기능이 마목 게시판 **비공개정보 접근 불가** ⓑ 관계자 특혜 배제·**수수료/조건 일반회원과 동일** ⓒ DSRV 연계 거래 **시장감시 별도 플래그**·정기 이해상충 보고. [근거 L6 §10 이해상충]
  - 2.3.3 취급자산/쌍: ETH·USDC·USDT 3종(Ethereum 단일), 쌍 ETH↔USDC·ETH↔USDT·USDC↔USDT. 거래지원 심사 통과·다크코인 금지 [근거 L4 §28, L2 §10의20]
  - 2.3.4 **교환 절차(수동)**: ①고객 교환요청(수량·방향) → ②외부지표 기준 스프레드 비율 제시 → ③**고객사 1인 확인 + DSRV 단일 승인**(BLF·KYT 자동검증 1차 필터·**불량 시 수동검증**) → ④**커스터디팀 콜드월렛 수동 집행**(재고 차감·전송) → ⑤보고·기록. 트래블룰 적용.
  - 2.3.5 재고·리스크: 교환재고 한도·재보충 절차(콜드), 스프레드 이탈·재고 부족 시 **요청 보류**. 자기재고 시장리스크는 소규모 한도로 관리(딜링북 아님).
- **2.4 신규 B — 교환 중개(마목·게시판형)**
  - 2.4.1 정의: 자사 커스터디 법인 고객 간 **ETH·USDC·USDT 교환을 중개**. DSRV=중개인, 비당사자·가격 불관여. [근거 L6 §2마목]
  - 2.4.2 **게시판형**: 시스템은 **의향 게시판**(게시·조회·상태)이 전부. 협의는 당사자 간(DSRV 비참여·기록만). 자동 매칭·체결엔진·오더북 없음.
  - 2.4.3 **단순 게시판 아님(심사 방어)**: 게재 검증 + 양측 KYC 담보 + 정산 연계 + 수수료 = 마목 해당성 4요소. [근거 L5]
  - 2.4.4 **중개 절차**: ①의향 게시(DSRV 보유·처분권 확인 후 게재, **옵션: 가격 이탈 자동중지 price-guard**) → ②당사자 협의(DSRV 비참여, **외부지표 임계 초과 시 RFQ 자동중지**) → ③조건 확정·승인(**고객사 1인 확인 + DSRV 단일**, 자동검증 1차·**불량 시 수동검증**) → ④**각자 이전 지시 → 커스터디팀 콜드월렛 수동 이전**(양건 확인 후 순차 집행·완결성은 운영절차로 담보) → ⑤보고·수수료 1% 양측. 트래블룰 적용.
  - 2.4.5 **가격 가드**: 외부 지표는 '가격 결정'이 아니라 게시자 보호용 **'이탈 감지 가드'로만** 사용(스테일 가격 방지) → DSRV 가격 불관여 유지. [근거 L6 이용자보호]
  - 2.4.5 가격: 당사자 협의, DSRV 불관여. 시세피드 미사용 → 연관 당사자·자전·통정 패턴 감시로 대체 [근거 L6 §10]
  - 2.4.6 인력 행위기준: 가격 개입 금지·정보전달/절차지원 한정·미공개정보 전파 금지·본인거래 금지
  - 2.4.7 **외부 VASP 참여(후속)**: 기본형=자사 고객 간(§28 미적용). 외부 참여 시 **§28 요건** [근거 L4 §28]
- **2.5 자산 보관·운영**: **현행 100% 콜드·수동 운영 유지**(인터넷 분리·에어갭·MPC·HSM·다중승인). 나목 교환재고도 콜드 편입. **자산묶음 = ①고객수탁 ②운영 ③나목 교환재고**. 입·출금·교환·정산 전부 **수동 집행·3면 대사**. USDT·USDC·JPYSC 노드([확인필요] 체인). **§11 콜드 요건 현행 충족** [근거 L7 §11]
- **2.6 기술·경쟁력**: MPC(하이파이브랩)·ISMS·특허 3건·노드 [근거 F3·F5·F6]
