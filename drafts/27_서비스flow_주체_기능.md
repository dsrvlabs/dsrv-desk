## 1. 주체 (Actors)

### 고객사 (ORG) — 담당자
| 주체 | 역할 |
|---|---|
| 교환 요청 법인 (나목) | DSRV에 ETH·USDC·USDT 교환 요청 |
| 매도/매수 법인 (마목) | 게시판에 의향 게시·협의·확정 |
| ORG 담당자 | 요청·의향 등록·이전 요청 + **1인 확인**(2인 기안↔승인 폐지) |

### DSRV (운영) — 역할별 분리
| 주체 | 역할 |
|---|---|
| Platform Admin | 전 ORG·정책·KYC 상태·마스터 통제(특권계정 PAM) |
| **나목 교환 운영** | 외부지표 스프레드 비율 제시·**재고 관리**·건별 수동집행 지시 |
| 마목 중개 운영 | 게재 검증·게시판 상태 관리·협의 채널 관찰(비참여) |
| 승인 담당 | DSRV측 **단일 승인**(결재선/maker-checker 없음) |
| 커스터디·키운영 | MPC·HSM 서명, **콜드월렛 수동 집행**(직무분리) |
| 컴플라이언스(AML)·보고책임자 | CDD/EDD·STR·트래블룰·위험평가 |
| 시장감시(독립) | 통정·자전·위장게시 + **나목 자전·재고세탁** 탐지 |
| 이용자보호 | 민원·설명·공시 |
| CISO / 개인정보보호책임자(CPO) | 정보보호·개인정보·사고대응 |

### 외부 시스템
사내 노드(Ethereum) · 사내 커스터디(MPC/HSM·콜드) · 트래블룰(CODE·VerifyVASP) · KYT(Chainalysis) · BLF(블랙리스트) · **외부 가격지표(스프레드 산정 참조용, 자동체결 미연동)** · FDS
*(자체 시세피드·자동 매칭엔진·외부 VASP는 미사용/2차)*

## 2. 서비스 Flow

### A. 온보딩
초대 → 이용·수탁 계약 → **CDD/EDD 오프라인(수기)**: 법인 실체·**실제소유자**·자금출처·제재 스크리닝 → 담당자 등록·**MFA** → 정책 설정(한도·화이트리스트) → 승인상태 활성(활성 전 조회만).

### B. 입금
고객 전용 주소 입금 → 사내 노드 감지 → **KYT/BLF 점검**(고위험 격리) → **콜드 보관**(수동 확인·반영) → 잔고 반영. *(핫월렛 스윕 없음 — 전량 콜드)*

> **진입점 분리(IA)**: 사이트 최상위 메뉴를 **「교환하기」(C-1 나목)** 와 **「거래하기」(C-2 마목)** 로 분리 — 두 서비스가 별개임을 UI로 드러내 행위유형 구분·차이니즈월을 뒷받침.

### C-1. 나목 교환 = 「교환하기」 (DSRV가 상대방 · 수동)
| 단계 | 내용 | 주체 | 통제 |
|---|---|---|---|
| ① 요청 | ETH·USDC·USDT 교환 요청(수량·방향) | 요청 법인(1인 확인) | 잔고·한도 확인 |
| ② 비율 제시 | **외부 지표 참조 스프레드 고정** 비율 산정·제시 | 나목 교환 운영 | 자체 시세산정·오더북 없음·재량 최소 |
| ③ 승인 | 고객 수락 → 정책·BLF·KYT **자동검증(1차 필터)** → DSRV 단일 승인 | 고객사 1인 → DSRV | **건별 승인**(자동체결 아님)·**결과 불량 시 사람이 수동검증** |
| ④ 집행(정산) | **커스터디팀 콜드월렛 수동 집행**: 재고에서 고객으로 전송 + 고객 자산 재고 편입 | 커스터디·키운영 | 트래블룰·3면 대사·재고 차감 기록, 즉시성 낮음(2영업일급) |
| ⑤ 완료 | 거래보고서·기록(스프레드 수익 구분회계) | DSRV | 기록 15년 보존 |

> 나목 방어(거래소·MM 아님): **오더북·자동 매칭·자동 체결 없음 + 외부지표 스프레드 + 건별 수동집행 + 단건 RFQ·블록딜(연속 양방향 호가 금지)**.
> 나목 이해상충(단일법인 마목·나목 겸업 → 차이니즈월): **정보격리(나목 데스크가 게시판 비공개정보 접근 불가) + 관계자 수수료 동일 + DSRV 연계 거래 시장감시 별도 플래그 + 'LP·MM·보증' 라벨 금지**.

### C-2. 마목 교환 중개 = 「거래하기」 (게시판형 · 당사자 간)
| 단계 | 내용 | 주체 | 통제 |
|---|---|---|---|
| ① 게시 | 매도/매수 의향(자산·수량·조건) 게시판 등록 + **옵션: 가격 이탈 자동중지(price-guard, 허용 편차·유효기한)** | 매도/매수(1인) | DSRV 보유·처분권 확인, 허위 게시 차단 |
| ② 협의 | 상대 관심 → **당사자 협의**(가격 당사자 합의, 구속력 없음) | 매도·매수 | DSRV **비참여·기록만**, 자동 매칭·체결 없음, **외부지표 임계 초과 시 RFQ 자동중지**(가드) |
| ③ 조건 확정·승인 | 수량·비율·일정 확정 | 고객사 1인 → DSRV | 정책·BLF·KYT·트래블룰 **자동검증(1차 필터)** + DSRV 단일 승인 + **불량 시 수동검증** |
| ④ 이전(정산) | 각자 이전 지시 → **커스터디팀 콜드월렛 수동 이전**(양건 확인 후 순차 집행) | 커스터디·키운영 | 완결성 운영절차 담보, 트래블룰, 3면 대사 |
| ⑤ 완료 | 거래보고서·**수수료 1% 양측** 정산 | DSRV | 기록 15년 보존 |

> 마목 방어: 게재 검증 + 양측 KYC 담보 + 정산 연계 + 수수료 = **단순 게시판 아님**(마목 해당성 4요소).

### D. 출금
담당자 기안 → 고객사 승인 → **정책 자동검증**(화이트리스트·한도·KYT·트래블룰) → DSRV 승인 → **콜드월렛 수동 서명·전송**(신규주소 지연발효) → 기록·통지.

### E. 예외·통제
- 통정·자전·위장게시 (마목) / **자전거래·재고세탁·비정상 교환패턴 (나목)** / **DSRV 연계 거래 이해상충(self-dealing)** → 시장감시 별도 플래그·검토 → 미소명 시 중단·**STR**
- **나목 재고 부족·스프레드 이탈** → 교환요청 **보류**(집행 안 함)
- 제재(BLF)·고위험(KYT) 적출 → 거래 차단(+ **§11② 사전통지·금융위 보고**)
- 조건 확정 전 무산 → 자산 이동·수수료 없음

| 온보딩·KYC | CDD/EDD(오프라인)·실소유자·자금출처·재이행·승인상태 게이팅 | F-6 |

| **마목 중개** | 의향 게시판·상태 관리·협의 채널(DSRV 비참여)·조건 확정·수동 이전 티켓 | F-1b |

| 로그·감사 | 행위/감사/API 로그·WORM·해시 무결성·거래 15년/AML 5년(개인정보 분리) | F-11 |
