# 원천자료 목록 — VASP 중개 신고 근거자료 관리대장

> **이 문서는?** VASP 「교환 중개」 신고를 준비하며 **근거로 인용할 수 있는 원본 자료**(법령·고시·확정 사실)가 무엇이고, 어디에 저장돼 있으며, 어디까지 확보됐는지를 한눈에 관리하는 대장입니다. 기획·신고 문서(`drafts/`)는 **반드시 여기 있는 원천자료를 근거로만** 작성합니다(기획이 기획을 근거로 삼으면 안 됨).
>
> 최초 작성·최종 확인: 2026-07-06

---

## 📖 읽는 법 (범례)

**저장 폴더의 뜻**
| 폴더 | 담는 것 |
|---|---|
| `knowledge/00` | 사업 요구사항·고려사항 (외국환·장기목표 등) |
| `knowledge/01a` | **신고 획득 요건** 법령·고시 |
| `knowledge/01b` | **운영 컴플라이언스**(AML·이용자보호) 법령·고시 |
| `knowledge/02` | **정보보호(ISMS)** 법령·고시 |
| `reference/` | 참고자료(벤치마크·규제 뉴스) — 근거로 직접 인용 X |
| `drafts/` | 기획·신고 초안 — 근거 아님 |

**확보 표시**  ✅ 원문 확보 · ⏳ 아직 없음 · ◐ 일부

**신뢰 태그**  `[확인필요]` 사실 미확정 · `[원문대조필요]` 원문은 있으나 사람이 원본과 대조 전(잠정) · `[로펌게이트]` 변호사 판단 필요

**인용코드**  각 자료에 붙인 짧은 꼬리표. 기획 문서에서 근거를 가리킬 때 씀 (예: 감독규정 28조 → `[근거 L4 §28]`). **중요도 순서가 아니라 단순 식별표**입니다.
`L` = 법령·고시 / `F` = DSRV 확정 사실 / `R` = 규제 변동 사실 / `X` = 외국환·장기목표 자료

> 법령 원문 취득 경로: 국가법령정보센터(law.go.kr) 또는 그 미러에서 원문을 받아 텍스트화. **사람이 원본과 1차 대조하기 전까지는 `[원문대조필요]`**로 둡니다.

## 🎯 확정된 사업 전제 (⓪ 요구사항)

> ⚠️ **2026-08-31(3차) 개정 — 나목 추가**: 2차(마목 단일)에 **나목(교환)을 추가**. 형태 = 「**나목 자사 상대방 교환(콜드·수동 최소재고) + 마목 게시판형 중개**」. 지갑서비스 형태확장은 여전히 안 함. (이력은 §0 변경이력)

- **신청 범위**: **나목(교환) + 마목(교환의 중개) 2개** 변경신고로 추가. 지갑서비스 형태확장 **안 함**. 기존 (다)이전·(라)보관관리는 그대로.
- **나목 = 자사 상대방 교환(콜드·수동 최소재고) — 단일법인 + 내부 차이니즈월** *(2026-08-31 확정)*:
  - 고객이 **DSRV와 직접** ETH↔USDC 교환(DSRV가 교환 상대방). 이용자 간 매칭·오더북 **아님**.
  - **최소재고**를 커스터디 **콜드월렛에 보유**, 교환은 **건별 수동(매뉴얼) 집행**(즉시성 낮음·2영업일급). 핫월렛 신설 없음.
  - **비(非)MM·비거래소 통제**: ① 교환비율 = 외부 지표 참조 **스프레드 고정**(자체 시세산정 없음) ② **연속 양방향 호가 금지** → 단건 **RFQ·블록딜**만 ③ **API 자동체결 금지**·수동 승인/타임딜레이 ④ 오더북·자동 매칭 없음 ⑤ UI에 **'공식 LP·마켓메이커·플랫폼 보증' 라벨 금지**(평판 뱃지로 대체).
  - **이해상충 통제(단일법인 차이니즈월)**: 마목 게시판 *운영*과 나목 *상대방* 겸업의 self-dealing 방지 — ⓐ **정보격리(blind wall)**: 나목 교환 기능이 마목 게시판 **비공개정보(상대방 최저 수용가 등)에 접근 불가** ⓑ 관계자 특혜 배제·**수수료/조건 동일** ⓒ DSRV 연계 거래는 **시장감시 별도 플래그**·정기 이해상충 보고. [근거 L6 §10 이해상충·L4]
  - ⚠️ **[로펌게이트] 나목 경계**: 자사 상대방 교환은 거래소·MM에 근접 → 위 비MM·이해상충 통제로 '자동체결 거래소·MM 아님'을 소명. FIU 사전면담 안건.
  - ⚠️ **[확인필요]** 별도법인(B) 분리안은 채택 안 함(B의 나목 VASP 필요성·'한 몸' 의심 리스크). "MiCA식 업권분리가 2026 FIU 기조"는 **국내 특금법상 명문 근거 없음** — 근거 없이 인용 금지.
- **중개 형태(마목) = 게시판형(경량)**:
  - 시스템은 **의향 게시판**(매도/매수 의향 게시·조회·상태 관리)이 전부. 협의는 당사자 간(DSRV 비참여·기록만).
  - **게시 옵션 — 가격 이탈 자동 중지(price guard)** *(2026-08-31)*: 게시자가 기준가 대비 허용 편차(%)·유효기한을 설정 → 협의 중 **외부 지표가 임계 초과로 벌어지면 해당 RFQ 자동 중지·양측 알림**. ⚠️ 외부 지표는 **'가격 결정'이 아니라 '이탈 감지 가드'로만** 사용 → DSRV 가격 불관여·자동체결 없음 유지(examiner 소명 포인트). 이용자보호(스테일 가격 방지) 강화.
  - DSRV의 중개 실질 = **게재 검증(보유·처분권 확인) + 양측이 KYC 완료된 자사 커스터디 고객임을 담보 + 성사 시 정산 연계 + 수수료 수취 + 기록**.
  - ⚠️ **[로펌게이트] 경계 이슈(신규)**: 신고매뉴얼상 **단순 게시판(장만 제공·수수료 없음)은 VASP 제외** → 너무 가벼우면 "마목 해당성 없음=신고 불가", 너무 무거우면(자동매칭·체결엔진) 거래소 오인. **위 '중개 실질' 4요소가 마목 해당성의 소명 근거** — FIU 사전면담으로 확정.
- **정산 = 기존 커스터디 수동 운영 그대로**: 성사되면 양 당사자가 각자 **이전 지시** → **커스터디팀이 콜드월렛에서 수동(매뉴얼) 이전 실행**(양건 지시 확인 후 순차 집행 — 운영 절차로 완결성 담보). 핫월렛 신설 없음, 자동 정산엔진 없음, 에스크로 없음.
